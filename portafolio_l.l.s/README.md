# Portfolio L.L.S - María Alejandra Acosta

> Academic Web Portfolio for Language Learning Strategies (L.L.S.)  
> Bachelor's Degree in Spanish and English Teaching - Universidad de Nariño

---

## Overview

This repository contains the academic single-page web portfolio of **María Alejandra Acosta**, crafted for the Language Learning Strategies course (7th semester) at Universidad de Nariño (San Juan de Pasto, Colombia).

The portfolio integrates academic reflections, interactive visual evidence, multimedia productions, diagnostic assessments, and pedagogical lesson planning under a sophisticated design inspired by **Chococat** (Sanrio) and modern Apple UI/UX principles (fluid microinteractions, glassmorphism, depth, and responsive symmetry).

---

## Design System & Theme: Chococat (Sanrio)

- **Canvas Surfaces:** Warm ivory (`#FFFDF9`) and soft toasted cream (`#F9F4EB`).
- **Typography Colors:** Charcoal carbon (`#231F20`) and chocolate walnut (`#5C4D44`).
- **Signature Accents:** Chococat collar cyan (`#4299E1`) and bell gold (`#ECC94B`).
- **Typography Pairing:** *Playfair Display* for academic headings, *Plus Jakarta Sans* for readable body text, and *Quicksand* for badges and controls.
- **Microinteractions & Transparencies:** 100% transparent vector illustrations (SVG), zero background boxes, glassmorphic navbar with blur, and responsive lightbox navigation buttons embedded inside media containers.
- **Zero Emojis:** Completely styled with original, clean vector SVG icons.

---

## Academic Modules & Evidence

1. **About Me:** Personal reflection and teaching philosophy on transforming foreign language education.
2. **Infographic:** Rebecca Oxford’s Language Learning Strategies taxonomy (Memory, Cognitive, and Social).
3. **S.I.L.L. Profile:** Strategy Inventory for Language Learning diagnostic results, strategic averages graph, and formal 3-page academic report.
4. **Metacognitive Strategies Video:** Academic video presentation examining Oxford’s 2017 strategic self-regulation framework.
5. **Zimmerman Model:** Self-Regulated Learning application across Forethought, Performance, and Adaptation stages based on "Wake Me Up When September Ends".
6. **Podcast Episode 4:** "From Theory to Practice" - theoretical discourse on SRL and everyday pedagogical decisions.
7. **Lesson Plan (TBLT):** 50-minute Task-Based Language Teaching implementation plan on meaningful memories and past tense.
